Roadmap: everything our model uses

Every idea behind the kolam model, in the order to learn it. Each one says what it is in plain words, where it shows up in our project, and where to learn it. Tick them off as you go (the ticks stay in this browser).

Your progress

Go in order: each track leans on the ones above it. Tracks 1–3 are the core (about 2–3 weeks at an hour a day). 4–7 you can pick up when we hit them.

The few sources worth your time

  • 3Blue1Brown, "Neural networks" (YouTube series): the best pictures for tracks 1 and 3. Start here.
  • Andrej Karpathy, "Neural Networks: Zero to Hero" (YouTube): builds everything in code, from backprop (micrograd) to a GPT ("Let's build GPT"). Track 1 and 3, hands-on.
  • CS231n course notes (cs231n.github.io): the classic CNN explanations. Track 2.
  • Jay Alammar, "The Illustrated Transformer": one long, very visual page. Track 3.
  • Dive into Deep Learning (d2l.ai): free book with runnable code for nearly every item here.
  • PyTorch "Learn the Basics" tutorial: how the ideas look in the library we use.
  • ONNX Runtime docs (onnxruntime.ai): web and mobile, track 7.
