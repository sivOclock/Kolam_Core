Transformers, from our own kolam code

A slow, visual course. One lesson per page. Every idea is tied to a real line in kolam_feed/model.py and drawn with the repo's own renderer. New to transformers? Start at Lesson 0.

Open these pages straight from the folder in a browser, no server needed. To build the next lesson, ask in the chat: “build lesson 2”. The code that draws the examples is lessons/make_assets.py (run with .venv/bin/python lessons/make_assets.py).
